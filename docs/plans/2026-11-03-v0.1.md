## 决策记录

- 2026-11-03：仓库名 `tracepost`（`CreatorHub` 已被占用），MIT，立即 public，规格迁入本仓库作为唯一 owner。
- 2026-11-03：技术栈 Python 3.12 + FastAPI + SQLite + Playwright + MCP Python SDK 2.x；前端用 Vite React-TS，构建产物由 Python 服务。没有选用 `fastapi/full-stack-fastapi-template`，因为它包含 Postgres、JWT、Sentry 等组件，超出本地单用户的需要。
- 2026-11-03：MCP SDK 2.x 用 `mcp.server.mcpserver.MCPServer`；工具返回 `dict[str, Any]` 才会产生 structuredContent，返回裸 `dict` 不会。
- 2026-11-03：`pyproject.toml` 和 `uv.lock` 只使用官方 PyPI，不提交本机镜像源配置。

## 验证证据

- 2026-11-03 Windows：`uv run pytest -q` 6 passed；`npm run lint` 和 `npm run build` 通过；`tracepost serve` 加 demo 数据库后，首页返回 200，`/api/contents` 返回 200，伪造的 Host 返回 400，浏览器中可见两平台 demo 数据、`— (not_exposed)` 和真实的 0；MCP stdio 客户端 `list_tools` 和 `call_tool` 往返成功。
